Security

CUDD Energy Services — TMV Preventive Maintenance · Effective date: July 23, 2026

1. Transport Security

All TMV Preventive Maintenance traffic is encrypted in transit with TLS. Access to the application and its APIs requires authenticated sessions; administrative functions require a valid bearer token.

2. Access Control

  • Field technicians are granted read-only access to their assigned work orders.
  • Administrators authenticate with a username and password; admin sessions carry a bearer token used for assignment, reassignment, and configuration changes.
  • Manager and admin passwords are hashed server-side (scrypt) and are never returned to the client.

3. Data Protection

Work-order data, checklists, and photos are stored on access-controlled servers. Uploaded photos are stored server-side and referenced by file name; they are not embedded in the database.

4. Authentication & Sessions

API requests that modify data require a valid bearer token. The Task.db admin console reuses the authenticated session to perform assignment-level actions such as reassign and delete. Close your session on shared devices.

5. Reporting a Security Issue

To report a suspected vulnerability or security concern, contact the PM app administrator through the dispatcher console. Do not disclose details publicly until the issue is resolved.
